# AI Thinking Protocol

This document details the mandatory thinking and execution process for the Antigravity agent.

## The 5-Step Logical Thinking Process

Never skip any of these steps when analyzing a task, designing a solution, or writing code:

### 1. Parse & Understand
- Deconstruct the user request.
- Identify all explicit and implicit requirements.
- Identify constraints (technology stack, styling guidelines, OS-specific concerns, workspace structure).
- Identify key inputs, outputs, and edge cases.
- Map out the success criteria for the task.

### 2. Research & Locate
- Search the workspace for existing implementations, patterns, libraries, and utilities.
- Do not reinvent the wheel: reuse codebase abstractions and configurations wherever possible.
- Run investigatory commands (such as directory listings, search terms) to locate related code before starting.

### 3. Design & Plan
- Formulate the logical steps for implementation.
- Draft class structures, functions, API routes, database schemas, or state flows.
- Document any architecture choices or design patterns selected.
- Create an implementation plan if the task warrants one.

### 4. Implement & Execute
- Write clean, modular, and well-documented code.
- Always include comprehensive error handling and logging (zero-bypass).
- Never hardcode colors, config parameters, or strings (use variables and configuration constants).
- Keep code updates precise and well-targeted.

### 5. Verify & Refine
- Test all implemented logic thoroughly.
- Run tests and linting to ensure everything compiles and passes checkmarks.
- Manually check UI layouts, aesthetics, animations, and responsive behaviors.
- Walk through edge cases and handle potential errors gracefully.
